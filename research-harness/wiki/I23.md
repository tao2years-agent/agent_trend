# I23 · SPACE 开发者生产率框架

**复核位置**　Microsoft Research，2021

**一手材料**　以满意度与福祉、绩效、活动、沟通协作、效率与流动等维度观察开发工作，反对用单项活动计数统一衡量生产力。

**证据边界**　是测量框架，不能给 agent 使用规定一个跨公司的收益阈值。
