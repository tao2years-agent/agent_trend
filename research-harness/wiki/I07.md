# I07 · GitHub 云端代理的责任边界

**复核位置**　PR 审批和 workflow 执行

**一手材料**　文档区分提出变更、运行 workflow、批准和合并。云代理不能批准或合并自己的 PR；默认路径中的特定 workflow 需要有写权限的人确认，部分行为可配置。

**证据边界**　触发人、自动化所有者和 app 身份不同，不能假定每份结果对应相同的审批规则。
