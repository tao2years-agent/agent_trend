0.126.0 (2026-11-18)

Before upgrading

  • Derived metrics. Check string formulas in derivedMetrics. Arithmetic, comparisons, ternaries and score names such as __count still work. Function calls, property access, assignments and formulas longer than 1,024 characters now stop the evaluation before any test cases run. For example, replace max(a, b) with a > b ? a : b. For more complex logic, use a function in a JavaScript config. Formula syntax · #12125
  • Full-repository code scans. Install and run Promptfoo with Node.js 24 or later for full scans. Diff-only scans still work on Node.js 22.22 or later. A full scan can share eligible committed text from the compared revision with the hosted scanner. Set diffsOnly: true in the code-scan configuration to share only the diff. #12185

Highlights

  • Evaluate GPT-6.2 Astra or Sol with openai:gpt-6.2-astra or openai:gpt-6.2-sol. Both use the Responses API by default. This release also adds Claude Fable and Mythos 5.2 and Gemini 4 Argon and Hydrogen. #12474 · #12358 · #12416
  • Use google:decisions:gemini-decision-1 to grade text, images, audio, video and PDFs. Gemini and Vertex also support file and live transcription. #12393 · #12151 · #12153
  • Promptfoo restricts access to saved cloud credentials on POSIX systems and redacts Azure Storage connection strings in logs and exports. #12177 · #12130
