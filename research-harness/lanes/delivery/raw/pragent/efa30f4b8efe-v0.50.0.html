⚠️ Breaking changes and upgrade notes

  • Host-only settings: Repository .pr_agent.toml files can no longer override GitHub pacing and retry settings (github.seconds_between_requests, github.seconds_between_writes, github.api_retries, github.ratelimit_retries), config.num_retries, azure_devops_server.agent_identity, custom-label settings (config.enable_custom_labels and [custom_labels]), or pr_code_suggestions.max_number_of_calls. config.num_retries is capped at 10. Per-directory .pr_agent.toml files also cannot set pr_code_suggestions.dual_publishing_score_threshold. Move values you rely on to host configuration. (#4445, #4475, #4485, #4632, #4745)
  • Comment arguments: config.ai_timeout and pr_code_suggestions.max_number_of_calls can no longer be set through command comments. (#4445)
  • Removed no-op settings: pr_code_suggestions.approve_pr_on_self_review and pr_code_suggestions.fold_suggestions_on_self_review are removed from the shipped configuration. PR-Agent warns if they remain set; they never changed /improve behavior. (#4598)
  • Custom provider integrations: Unused provider methods and capability names were removed. Review #4691 if a custom provider calls those internal methods.
  • Auto-approval: config.enable_auto_approval is now host-only. The auto-approval path remains disabled in this release. (#4700)

🔐 Trusted Publishing

PyPI releases now use PyPI Trusted Publishing through GitHub Actions OIDC and produce package attestations. The release workflow rejects commits that are not reachable from main. (#3909)
