# 同一篇开发者研究，按人和按仓各算一次

为查明采用 agent 后“评审变快”和“测试纪律改善”到底各有多少支持，我们从作者 Zenodo 包取得 437,566,326 字节的固定档案，核对公开 MD5。用独立程序读取实际 PR、文件和评审处理表，以作者的期前/期后及窗口过滤重算 11 个结局。每个结局先算个体变化，再比较两组变化分布，并对 11 项一起调整多重检验。为避免重复传播公开账号和 PR 文本，此处只发布分组计算与汇总，数据可从原作者重取。[正式论文表 2–4](https://doi.org/10.4230/LIPIcs.ESEM.2026.67) · [原始复算包](https://doi.org/10.5281/zenodo.20442228) · [输入列和版本](manifest.json)

**原文的总样本与单个指标的分母不同。** 按作者主脚本的“作者”分组，PR 指标有 633 名处理组、228 名对照组贡献前后两期；按“作者×仓库”分组则有 669 与 232 个组合，论文表 1 写 669 与 228。对照组相差四个组合，原因尚未确定。在评审周转的主规格中，实际进入的是 532 名处理组和 201 名对照组评审者。不能用 669 表示每个结局上参与比较的独立开发者。我们重现出正文表 2 中 PR 描述变化的中位数差 121.5、秩效应 −0.323，以及表 4 中评审周转差 −1.54 小时、校正 p≈0.090。后者若只看未经多重调整的 p≈0.049，会给出不同结论。各项数值留在 CSV；与出版物末位舍入有小偏差。

四种规格都沿用已脱离原始实验的观察数据。匹配清单过滤了对照仓，不能消除未观测混杂；本次敏感性有意固定指标聚合函数，与作者另一个 matched 脚本在 test ratio 上用 mean 的选择不同。各项秩检验未给出团队层面的随机效应，这里也没有重跑论文的固定效应、安慰剂等所有模型。因此复核支持其中若干可重现数值，同时收窄两项测试指标的外推范围。[44 个可复核结果](sensitivity.csv) · [事前说明](protocol.md) · [复算程序](compute.py)
