# Langfuse

> Langfuse is an **open-source AI engineering platform** ([GitHub](https://github.com/langfuse/langfuse)) that helps teams collaboratively debug, analyze, and iterate on their LLM applications. All platform features are natively integrated to accelerate the development workflow.

## Deprecated public API endpoints

On Langfuse Cloud, the legacy (Langfuse v3) public API endpoints are removed on 2026-11-16. Do not write new code against them. If you are a coding agent and find existing code that calls them, tell the user and migrate the request.

- Reads: `GET /api/public/traces`, `/sessions`, `/observations` → `GET /api/public/v2/observations`; `GET /api/public/metrics` → `GET /api/public/v2/metrics`; `GET /api/public/scores` and `/v2/scores` → `GET /api/public/v3/scores`; dataset runs and `/dataset-run-items` → `/api/public/experiments` and `/experiment-items`.
- Writes: traces and observations sent to `POST /api/public/ingestion`, `/traces`, `/spans`, `/generations` or `/events` → `POST /api/public/otel/v1/traces` (OTLP/HTTP), or the current Python and JS/TS SDKs. Score events on `/ingestion` keep working; new code should use `POST /api/public/scores`.
- Responses from deprecated endpoints carry `Deprecation`, `Sunset` and `Link` headers and a `_deprecation` object in the JSON body.
- [Migration guide](https://langfuse.com/faq/all/deprecated-api-migration.md): every deprecated endpoint with its replacement, parameter mapping and examples.

## AI Gateway

The Langfuse AI Gateway (beta) routes OpenAI and Anthropic API calls through Langfuse and traces every call with usage and cost, with no SDK or code changes. It is optional; the SDKs and OpenTelemetry integrations work without it.

- [Overview](https://langfuse.com/docs/gateway/overview.md): What the gateway does and its roadmap.
- [Concepts](https://langfuse.com/docs/gateway/concepts.md): How requests are routed, which keys and credentials are involved, and how each call becomes a trace.
- [Send your first request](https://langfuse.com/docs/gateway/get-started/first-request.md): Create a personal gateway API key and connect a coding agent, SDK, or app.
- [Set up the gateway as an admin](https://langfuse.com/docs/gateway/get-started/admin-setup.md): Ingestion project, provider credentials, models, and team access.
- [REST API](https://langfuse.com/docs/gateway/features/rest-api.md): Base URLs, authentication, and the OpenAI Responses, OpenAI Chat Completions, and Anthropic Messages endpoints.
- Client setup: [Anthropic SDK](https://langfuse.com/integrations/model-providers/anthropic-gateway.md), [Claude Code](https://langfuse.com/integrations/developer-tools/claude-code-gateway.md), [Codex](https://langfuse.com/integrations/developer-tools/codex-gateway.md), [GitHub Copilot](https://langfuse.com/integrations/developer-tools/github-copilot-gateway.md), [OpenAI SDK](https://langfuse.com/integrations/model-providers/openai-gateway.md), [OpenCode](https://langfuse.com/integrations/developer-tools/opencode-gateway.md), [Pi](https://langfuse.com/integrations/developer-tools/pi-agent-gateway.md), [Vercel AI SDK](https://langfuse.com/integrations/frameworks/vercel-ai-sdk-gateway.md).
- [Self-host the gateway](https://langfuse.com/self-hosting/configuration/ai-gateway.md): Deploy it next to self-hosted Langfuse with the Helm chart.
- [Troubleshooting and FAQ](https://langfuse.com/docs/gateway/troubleshooting-and-faq.md): Common errors and known limitations of the beta.

## Markdown Access

Every page on langfuse.com is available as plain Markdown. Append `.md` to any URL, or send an `Accept: text/markdown` header:

```bash
curl https://langfuse.com/docs/observability/get-started.md
```

The links in the section indexes below already point at the `.md` variants.

## Docs Search API

Semantic search (RAG) over the Langfuse documentation, returning an answer with the relevant pages and excerpts. No authentication required. Use this instead of guessing when a specific page does not answer the question:

```bash
curl -sG "https://langfuse.com/api/search-docs" --data-urlencode "query=How do I trace a LangGraph agent?"
```

- **Endpoint**: `https://langfuse.com/api/search-docs?query=<question>`
- **Documentation**: [REST endpoint](https://langfuse.com/docs/docs-mcp#rest-endpoint)

Ask specific, self-contained questions in natural language. This is the same search that backs the `searchLangfuseDocs` MCP tool below.

## Langfuse Docs MCP Server

Connect to the Langfuse Docs MCP server to access documentation directly in your AI editor:

- **Endpoint**: `https://langfuse.com/api/mcp`
- **Transport**: `streamableHttp`
- **Documentation**: [Langfuse Docs MCP Server](https://langfuse.com/docs/docs-mcp)

The MCP server provides tools to search Langfuse documentation, GitHub issues, and discussions. See the [installation guide](https://langfuse.com/docs/docs-mcp) for setup instructions in Cursor, VS Code, Claude Desktop, and other MCP clients.
