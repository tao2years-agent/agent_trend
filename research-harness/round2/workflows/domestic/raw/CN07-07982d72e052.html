🚀 CodeBuddy Code v2.140.0 发布 ​

📦 版本信息 ​

组件版本
CodeBuddy Code CLIv2.140.0
Agent SDK JSv0.3.247
Agent SDK Pythonv0.3.246

✨ 新功能 ​

Web UI 团队会话群聊气泡 ​

CBC WebUI 的消息队列会解析成员消息中的发送者、摘要和正文，以可区分成员身份的群聊气泡展示，消息进入对话流后保持相同样式。同时增大对话输入框底部留白，输入体验更舒适。

stream-json 模式新增 steer 控制信号 ​

在 --input-format=stream-json 下可通过 control_request（subtype steer）向正在执行的 Agent 轮次注入用户消息，语义对齐 ACP session/steer，供 SDK/网关调用方（如云助理 sandbox-proxy）后续接入。

🔧 改进优化 ​

  • Web UI 对话流排版优化：正文、思考与工具组以连续轨道交错展示，用户消息气泡改为中性灰色；REPL 工具折叠态聚焦执行意图，展开态按 Code / Output 分区展示并支持 JavaScript 语法高亮
  • REPL 大输出不再撑爆上下文：超过 30KB 的工具结果自动截断并落盘，模型面收敛为占位符，需要时可读取完整内容；长会话压缩时旧 REPL 结果也会被折叠
  • Web UI 项目目录菜单优化：目录菜单默认向上展开，新建智能体菜单使用页面级浮层，修复搜索结果被输入框遮挡的问题
  • Web UI 收件人搜索体验优化：移除突兀的聚焦描边，候选列表以浮层展示，不再撑开页面布局
  • 安全中心规则增强：文件、命令、网络能力按统一名单顺序执行规则并支持会话内热更新；文件写入前重新校验目标真实路径；Grep 搜索执行前应用读取规则

🐛 问题修复 ​

  • 后台任务通知退出码：完成通知补充可信退出码，退出码未知时明确提示以命令输出为准，不再误判成功或失败
  • 挂载点/软链环境 AI 回复丢失：修复虚拟磁盘挂载或软链场景下同一次对话被拆到两个目录的问题，存量历史无需手工迁移即可找回
  • 团队停止按钮静默失效：修复团队主 Agent 回合结束但成员仍在执行时点击停止被吞掉的问题；取消一个会话不再影响其他会话的团队成员
  • 云沙箱 cancel 后消息零回复：修复 cancel 中断后状态机卡死、后续所有消息无响应的问题
  • 子 agent 压缩结果丢失：修复上下文自动压缩后父 agent 拿不到真实结果、只能重跑一遍重活的问题
  • 团队队员模型与工具配置丢失：修复队员被重新唤醒后模型回落到主对话模型、工具禁用项失效的问题，后台任务 agent 一并修复
  • REPL 交互工具被误拦截：修复 REPL/沙箱模式下 AskUserQuestion、ExitPlanMode 等交互工具无法弹出问题面板/计划审批的问题
  • 界面显示 <system-reminder> 泄漏：修复记忆笔记等注入内容中的伪闭合标签导致内容残渣泄漏到用户消息区的问题
  • Windows Ctrl+G 记事本打不开：修复未设置 $VISUAL/$EDITOR 时记事本窗口不上前台、界面死等问题
  • WebFetch 图片/二进制分流：图片或文件 URL 不再走 AI 摘要，引导先下载再读取
  • 后台任务定位：TaskStop / TaskOutput 对不存在的 task_id 明确报错并列出当前运行中的任务
  • 其他修复：stream-json steer 处理器编译失败、Miora 凭据重复弹外发审批、插件市场更新被本地安装态阻塞、Web UI PWA 清单鉴权失败、pyenv 环境兼容、Monitor WebSocket 规则执行等

📝 文档更新 ​

  • -y 与 CODEBUDDY_IS_SANDBOX 风险说明：codebuddy -h 的 -y 说明更新——默认仍会询问 HIGH/CRITICAL，隔离沙箱 full pass 需设置进程环境变量 CODEBUDDY_IS_SANDBOX=1，并补充高危风险声明
