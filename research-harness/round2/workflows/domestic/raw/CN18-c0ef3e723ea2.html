重磅更新：TraeWork 已升级为全新的 TRAE

复制页面

TraeWork 与 TraeCode 将融合升级为全新的 TRAE，成为覆盖开发全流程的一体化平台。从需求拆解、方案生成到成果交付，全新 TRAE 支持在 Agent 模式与 IDE 模式之间无缝切换，帮助你更高效地推进任务并交付成果。

提示

前往 TRAE 官方下载中心，下载并安装全新版本的 TRAE。

关于全新的 TRAE

双端融合：一个入口，两种模式，三端同步

过去，TraeWork 更偏向办公、任务和内容生成，TraeCode 更专注专业开发者的编码需求。

但用户真实要完成的事，并不会天然分成「办公」和「写代码」。做一个产品 Demo，既需要需求拆解，也需要页面设计、代码实现、测试检查和交付说明；推进一个项目，也可能同时涉及文档、数据、任务、代码和汇报。

双端融合后，全新 TRAE 用一个统一入口承接这些连续任务，并支持 Agent 模式与 IDE 模式无缝切换

  • Agent 模式 适合从想法拆解到交付结果：新手开发者可以一步步做出 Demo，专业开发者也可以跨项目调度多个 Agent 并行推进任务。
  • IDE 模式 保留完整智能开发环境，适合单项目深度代码编辑与精细调试。

同时，全新 TRAE 覆盖桌面端、Web 端和移动端。你可以在电脑上启动任务，在移动端查看进度、补充要求，再回到桌面继续深入开发。项目、任务和产物围绕同一套工作流持续推进，不因设备切换而中断。不同能力在同一条任务链路里自由衔接，让 AI 不只停留在某个环节，而是参与从想法到结果的完整过程。

通过此次升级，我们希望：

  • 回到 TRAE 的初心
    TRAE 的起点，是 The Real AI Engineer。我们希望它不只是一个 AI Coding 工具，而是一个真正能理解目标、推进任务、解决问题的 AI 工程师。全新 TRAE 合并后，用户无需区分入口，也不必先判断从代码、任务还是设计开始，只要说清楚想完成什么，就可以直接开始。
  • 不止写代码，而是把事情做成
    AI Coding 的价值，不只是生成代码，而是在真实项目里解决问题。全新 TRAE 会继续强化项目理解、代码生成、文件修改、命令执行、报错分析和结果验证能力，并通过更强模型、更稳定的 Harness 工程执行能力，让 AI 不只是“会回答”，而是能持续推进任务。
  • 让 AI 更主动，降低创造门槛
    AI Coding 正在从“人给指令、AI 做一步”，走向“人提出目标、AI 持续推进”。全新 TRAE 会继续提升目标理解、工具调用、结果检查和自主修复能力，减少用户反复介入，让专业开发者更轻松地推进复杂任务，也让更多人能从一句想法开始，做出可打开、可点击、可验证的结果。

Agent + IDE 双模式：从全局推进到深度开发

全新 TRAE 同时支持 Agent 开发模式和 IDE 开发模式，覆盖从任务推进到深度编码的不同开发场景。

在 Agent 开发模式 中，你可以在同一个工作台里管理多个项目，调度多个 Agent 并行推进不同任务；也可以在多目录下发起本地任务，或连接 SSH 远程开发环境，让任务在更灵活的环境中持续推进。当需要深入代码细节时，可以随时切换到 IDE 开发模式，继续完成代码编辑、调试和深度开发。

Agent 模式负责全局推进，IDE 负责深入开发。对于非专业开发者，它更像一个从想法开始的全能开发助手；对于专业开发者，它更像一个可以跨项目、跨任务调度 Agent 的开发工作台。

一个活动报名网站，可以怎么做？

比如，你想做一个活动报名网站。过去需要整理报名规则，再画页面结构，接着写前端页面、处理表单逻辑、补充测试，最后再整理一份说明文档；现在，可以直接从 Agent 模式开始，拆需求、出页面方案、写代码、做测试并整理交付说明。

复杂任务还可以交给多个 Agent 并行推进：一个梳理页面结构，一个生成代码，一个检查表单逻辑，一个整理交付文档。当页面需要微调、交互需要优化、代码需要深度修改时，再回到 IDE 模式继续处理。

从一个想法，到一个能打开、能点击、能继续迭代的 Demo，路径更短了。

统一工作流：把多项能力整合进全新 TRAE

双端融合后，自动化任务、模板库、我的助理和项目产物会进入全新 TRAE 的统一工作流。和 Agent 开发模式、IDE 模式一起，组成从任务发起、过程推进到结果沉淀的完整链路。

  • 自动化任务，把重复流程交给 Agent
    定期整理项目进度、运行固定检查、汇总测试结果、生成报告等重复任务，都可以交给 Agent 持续执行。
  • 模板库，让常见场景快速启动
    产品方案、页面搭建、数据分析、技术文档等高频任务，可以直接基于模板开始，不必每次从空白页重新搭建。
  • 我的助理，把开发之外的交付也接进来
    代码之外，还有文档、汇报、协同和整理工作。我的助理让这些非编码环节也能接入同一条任务链路。
  • 项目产物统一管理，开发过程更清晰
    代码变更、HTML、PPT、Word 文档、图片、视频、报告等内容，都会统一进入 「我的产物」。不用再从聊天记录里翻找结果，也不用担心不同任务的文件散落在各处。

不只是方便找文件，更是让每一次 AI 协作沉淀为可回看、可展示、可继续迭代的资产。

获取全新的 TRAE

新用户：直接安装全新的 TRAE

前往 TRAE 官方下载中心，下载并安装全新版本的 TRAE。

老用户：将 TraeWork 升级为全新的 TRAE

操作步骤

  1. 将 TraeWork 桌面版更新到最新版本。
  2. 打开 TraeWork 桌面版。
    页面将显示以下 TraeWork 升级提示：
  3. 根据需要勾选以下选项：
    • 升级完成后，同时卸载 TraeWork：升级至 TRAE 后，系统将自动卸载当前的 TraeWork 桌面版。
    • 卸载后删除 TraeWork 本地数据：卸载 TraeWork 桌面版时，系统将一并删除其本地数据，包括日志、AI 数据等。已同步至 TRAE 的数据不受影响。
  4. 点击 立即升级 按钮。
    系统将自动下载并安装 TRAE，同时把你的聊天记录、账号数据、个人资料、商业积分、登录状态和本地数据等从 TraeWork 迁移至 TRAE，无需手动操作。

注意事项

升级过程中，请保持网络连接并勿关闭电脑，以免升级失败。
