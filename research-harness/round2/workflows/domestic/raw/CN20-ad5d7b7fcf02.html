用户指南/个人设置/GitHub 授权

GitHub 授权

复制页面

将 GitHub 集成至 TRAE 客户端后，可以显著提升开发效率。你无需在 TRAE 客户端和 GitHub 之间频繁切换，即可在 AI 辅助编码后，快速发起代码合并请求（Pull Request，PR），或让 AI 协助检查代码变更。

在 TRAE 企业版控制台中，你可以管理 GitHub 与 TraeWork 间的连接状态，包括建立连接和断开连接。

支持的客户端

TraeWork 桌面版和网页版

注意事项

使用专属域名登录 TraeWork 桌面版或网页版时，不支持进行 Github 授权连接，需要切换至公网域名配置授权。

连接 GitHub 至 TraeWork

  1. 登录 TRAE 企业版控制台。
  2. 前往 个人设置 > 外部应用授权。
    你将进入外部应用授权管理面板。
  3. 在 GitHub 条目处，点击 连接 按钮。
  4. 根据界面提示，完成登录与授权流程。

管理 PR

关于如何在 TraeWork 中通过 GitHub 来管理 PR，参考创建 PR 和由 AI 检查 PR。
