Keep chatting while workspaces run

Ask follow-up questions in Agentic Batch Changes while workspace runs continue in the background.

You can now keep talking to Agentic Batch Changes while the workspaces it started are running. Ask how a migration is going or what has finished so far.

Before, the agent kept its turn open until the workspace runs finished, which blocked follow-up messages. It now starts the runs and ends its turn, leaving the conversation available while execution continues.

The agent resumes automatically to review results and investigate failures. It can inspect a failed workspace while others are still running, then report on the completed work.

Included in Sourcegraph Cloud and Sourcegraph self-hosted 8.2.
