# reviewer 路由的时间留出协议

登记于查看表结构和前一项 AIDev 研究的总体统计后、首次统计 reviewer 身份、训练模型、查看任何路由命中率之前。同一项目此前已知 2026 年 2 月的 67,327 个 agent PR 和 8,700 个仓库，并做了抽样的正式决定比例估算。本次为完整二月 cohort 的新问题，不宣称完全盲选月份。

使用 AIDev v5 固定 commit b8dc67df93e7c11f6f20c84129db7232eb1ec253，AIDev-pop 的 PR 与正式 review。训练窗口为全部可观测历史到 2026-02-01 00:00 UTC 之前，review 的 submitted_at 严格小于截止日、且不早于其所评 PR 创建。测试 cohort 为 2026-02-01 至 03-01 前创建的全部有合法 id、repo 和创建时刻的 PR。正式标签为创建起 30 天内的首个个人账户 APPROVED 或 CHANGES_REQUESTED。最晚观察不超出作者 03-31 快照。用户类型与已知机器人过滤沿用前一研究。初次正式决定同秒多账户，按 review 数字 ID 升序决胜，另量化歧义。无个人标签的 PR 计入请求覆盖和占用名额，但不能当作预测错误或正确。

预测时点是 PR 刚建立、尚无当前 PR 后续行为。基础只允许 repo、UTC 时间、该仓过去的 PR/个人决定关系。文件变更表 12.45 GB 包含整条 PR 的提交细节，无创建时路径快照的保证；timeline 的 actor、assignee 不是已核验的 requested_reviewer 字段。在证明“是谁被请求、以及在 PR 建立时已可见”前均排除；不使用提交者偏好、组织目录、私有历史、未来合并结果或留出标签。例外工单/值班事件不可直接识别，本研究只估计在 agent PR 开立时预判首位可见正式 reviewer 的能力。没有在线触达。

预设规则：(F) 按仓内 reviewer 历史参与的不同 PR 数排序，再按最近事件；(R) 按同仓最后一次可见正式决定排序，再按频次；(P) 按仓内成为历史首个正式决定者的 PR 数排序，再按最近首次决定；(G) F 的可弃权版：只让参与至少两个该仓历史 PR 的个人进入列表；(B) G 上加预算：每人全仓每日最多作为首选三次，所有留出 PR 按创建时间、同秒 PR ID 顺序占用预算，跳过已满者。每次返回最多 Top3，只向首位计费；这些是假想容量，不是假设该人有空。所有数字在结果前固定；不同账户平局使用固定私密映射次序，仅存不含身份的统计；跨 PR 排序只用预测时刻既有信息。

同时报告首选和前三命中，分母为全体有标签 PR（弃权算未命中）、以及各规则路由且有标签 PR；覆盖以全体测试 PR 计，另报有标签覆盖和历史冷启动。各仓均权的命中均值与按 PR 计的微平均并列，报告推荐给最繁忙前十个账户的比例和每人每日峰值。按最少仓内历史 PR 数 1、3、10 做重算，区分完全无历史的仓和本次正确人选尚无该仓历史。比较月初冻结与每次只允许提交时间严格早于该 PR 创建的滚动更新，以及 7 日和 30 日标签；历史及当日分配均须含无标签 PR，不在看完答案后才选样。

发布完整总体分母和可复算的匿名充分统计，不输出账户名、真实仓或 PR 身份、评语、标题、变更文件、授权列表或任何实际指派。路由准确仅预测谁过去留下决定，既不能证明该人具备业务 owner 权限，也不能估算联系后能节省的时间。原始列块只在既有本机临时缓存或从官方固定版本重新取得。
