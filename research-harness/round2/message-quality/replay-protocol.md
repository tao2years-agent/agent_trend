# 交接卡离线对照预登记

同一问题有五个 coding agent 的补丁。每张卡代表一个补丁的原始解释或审计后解释；五次问答采用同一既有评估器的五次作答。排卡只看作答选择，故障标签取固定作者 PBT 与独立 SWE-bench Verified 两层。确认选中“测试将失败”才算失败票；“信息不足”、缺答或未解析选项均不算，不用真实结果排卡。并列按固定顺序 refact、Lingxi、OpenHands、mini、trae；无过滤基线按该提交归档顺序，不把它叫生产到达时间。检查前三张是否包含至少一个真正失败的补丁，在存在失败的 issue 子集上计算，并单报全通过问题的错误呼叫。三种卡序是固定顺序、按原解释失败票排序、按审计后解释失败票排序；再比较三票起展示的弃权策略。每题最多三卡、不跨题算票；两套标签都保留且先决条件相同。模拟没有事故现场、真实消息顺序、技术员或秒表，不回推 GFM 的论文效果。
