# 选择与判定协议（观察任何测试输出前固定）

选择 SymPy。它是公开、纯 Python 的数学软件，Windows 本机已有 Python、mpmath、pytest。一般数值或符号行为缺陷不用付费服务、系统服务或联网测试。固定 Princeton 官方 SWE-bench Verified test 分片，按 instance_id 的数值 PR 后缀升序。仅纳入 sympy/sympy，FAIL_TO_PASS 和 PASS_TO_PASS 均非空、名称能定位到测试文件和函数、patch 与 test_patch 均存在的行。排除涉及漏洞、注入、凭据或安全修复的条目以及依赖外部网络服务的任务，记录理由。在较新的维护版本（version 数值 >= 1.10）中取最先出现的 8 项，以规避 2010 年代解释器 API 的已知迁移；若这些不足则沿相同顺序纳入较老版本。任何失败保留，首次 8 项为固定分母。若上游标签格式需正规化，只改变映射，不按执行结果换样。

每项使用数据集指定的 base_commit 和未改动的 gold patch、test_patch。对同一基线执行三个阶段：原始测试和原代码、装入上游新增或增强测试后的原代码、同样测试加金标生产改动。每个阶段运行全体 FAIL_TO_PASS 加 PASS_TO_PASS 中按名字排序前五个，后者预算事先固定。报告节点级 pass/fail/缺失/skip/预期失败/环境错误、运行退出码、资源限制和分母。未知结果不可算通过。另做丢掉 FAIL_TO_PASS 后仅凭回归冒烟的敏感性比较。补丁适用异常或运行环境失败若可修正，在所有相关程序统一修正并留存初次记录；不能用修补后的测试伪装成上游原件。只允许读公开可得源码，所有评价为本地局部复验，不声称复现官方 Docker 全套分数或评价任何代理。
