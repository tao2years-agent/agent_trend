# 八个官方研究轨的题名普查与摘要抽核

冻结范围是 ICSE、FSE、ASE、ISSTA 各 2025、2026 两届的主研究轨。采集单位是官网指认的 accepted paper，以轨道内 event UUID 作主键；以 DOI、题名归一化作跨来源核对，不按标题相似度合并论文。学术成果可发表于期刊再在会议报告，计入依据是该届官方列入主研究轨；Journal First、SEIP、Industry、Tool Demo、Keynote、NIER 等单列轨道不进入分母。若轨内还分 Experience、Tool、Research/technical，保留明示的子类型和 unknown，不把每条都说成同一种研究论文。若官方缺少专用 Accepted Papers 表，检查带 track 明示标签的固定分轨目录及 DOI 出版源并披露，禁止将综合日程当研究轨全集。

**预置研究问题与检索式。** 搜索场域是英文题名，忽略大小写，连字符归一为空格；每条题名可命中多组。确切词形及边界由 `rules.json` 固定。Q1 寻找 agent 如何分工、委派、传递状态或暴露真实轨迹；Q2 寻找交付/验证闭环中重跑、回归、构建、依赖及发布控制；Q3 寻找人怎么审阅、解释、接管和分配维护责任；Q4 寻找个体或组织层面的采用、协作、活动、质量或工作量效应；Q5 寻找评测有效性、测试预言、变形关系与可复现性。五组对单纯模型内核/宽泛“AI”不设通配。词表首版冻结于读取八个接受目录前，仅已确认 FSE 2025 的 HTML 形态可解析。

**筛选。** 全部题名明确标记 rule-hit 或 rule-miss；命中是一候选，未命中不是无关。人工复核按预先固定的 hash 排序，从每届 hit 和 miss 各取两篇（若遇缺乏正文/摘要保留失败和替代）；再目的性复核最可能补上缺口的代表题名。分类为 relevant、adjacent、off-topic、unknown；标准分别为能直接回答上述问题、有可迁移机制但非研发场景/决策、语词歧义，以及证据不足。小样本的误命中/漏命中只描述已查记录，不代表八轨全集的精确率或召回率。分层选择不能估算市场占比。

**证据层级。** 预置规则的“召回”报告为该来源召回多少候选及现有研究能命中多少（已知阳性回收），不将无全面标注的分母冒充召回率。增补案例优先用作者/会议摘要，标注回顾性设计和产品试点中能推翻转用判断的观察。优先选缺失决策机制，不重复计算 R2 既有论文。记录官网时间点、目录标题与原始文件 SHA-256 以便下次复核。
