# 第二轮检索预置与冻结点

V1 的 1,738 个 event UUID 和五组词不改写。V2 仅在原规则未命中的题名中加入工作对象、工作会话及交付验证对象的同义词；三组精确表达式位于 rules.json。在抽取新摘要前写下此式；不看新增摘要再调此版本。用词来自第一轮已观察的 7 个直接漏检、6 个已知 P 系列漏检和 F01–F06 的工作对象。已观察样本即使能被召回也不能充当泛化证据。

把以下条目明确排除在新盲抽框外：V1 的 142 个命中、32 个分层样本、5 个目的补充、F01–F06、原 P01–P20 和 round2/papers/results.tsv 中可按正规题名匹配的论文。对剩余条目按 V2 是否命中分两层，在每个会议年份×层内，取 SHA256("v2-blind-20261120|" + event UUID) 升序前 8 篇；不足时全取。人工看作者摘要后逐项记录 R/A/O/U 及具体理由，选出的深挖问题须能改变一个产品决策。估计的是这次保留集中的直接相关率，按层报告 Wilson 95% 区间；对抽尽的小层普查区间是该层真实比例，不合并样本当作真实全集召回率。

作者与机构只按论文署名归属。谱系需有至少两篇同一作者或明确研究项目的证据；同校不同作者、同名缩写、跨年同校不构成一条连续研究线。组织控台侧的试点建议与论文实测分栏。
