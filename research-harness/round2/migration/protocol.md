# 实验前定义 · 2026-11-20 上海

检验问题：在六个历史 Python 项目的两个固定发布快照上，不调用模型，仅靠确定性工具能覆盖多少字面量 str.format 迁移？两种工具未处理的余项、产物语法可解析及重复执行是否稳定，分别意味着什么？结果用于设定跨仓迁移试点的规则基线。

采用 Django 3.2.25/5.2.1、Requests 2.25.1/2.32.3、urllib3 1.26.18/2.4.0、Click 7.1.2/8.2.1、NetworkX 2.5.1/3.4.2、Pygments 2.10.0/2.19.1。比较各自发布包内所有自带 Python 文件，分开标注测试目录；轮子里没有打包的源码不作推断。选样覆盖 Web、HTTP、命令行、图计算和语法高亮，不代表所有语言或企业代码。两个版本不是连续时间窗。分母包括零命中快照。转换目标为字面量字符串作接收者的 format 调用。语法树的净减少为覆盖代理；遗留 API 的所有合法用法未必适合改写。

Ruff 只开 UP032、不接受声明为不安全的自动修复；Flynt 关掉百分号转换，保持默认非激进模式。每个工具从相同原件开始，对同一副本运行两次。保留原包发布者 SHA、各项目和文件的前后计数、退出码、二次变化、未处理的难例与正反例。工具仅在隔离临时目录内写。可解析、可重复、观测行为等价三种门槛分别列出。另用手写的小程序检查普通位置参数、重排、有副作用、格式化方法、副作用先后和未消费的参数；这些是机制探针，不代表生产回归套件或一般正确率。未做付费 agent 租户同场对照，不能得出 agent 的边际效果。
