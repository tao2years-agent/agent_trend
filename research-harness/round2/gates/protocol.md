# 在看到新候选结果以前固定的实验

沿用 round2/oracles 固定的八个 SymPy 版本、原问题、上游金标与 test_patch。已知前次上游测试表现与部分 hunk 实验。仅涉及普通数学、符号与格式边界，禁止引入服务调用或安全任务。

**候选。** 对金标中实际新增或替换的生产行建立集合；只在这些行的 Python AST 节点做一个本地替换，不改测试。候选种类预定为数值邻界、算术或逻辑操作符、比较、数值假设属性（is_number→is_real/is_imaginary/is_rational/is_integer；is_zero→is_nonzero/is_positive/is_negative）、分片边界、显式参数/关键字和基类省略、标点容器文本及 min/max 对调，另包含 return 空容器/恒等表达式变体。不制造指定例外值上的恶意分支、查表硬编码或针对测试名字的特例。限定在金标行的同一表达式/词位；每个候选编译、检查 AST 差异、按结果 AST SHA 去重。每题最多 10 个，按算子类别分桶，桶名与桶内候选以固定 seed 的 SHA 排序，轮流各取一个直至满额；保存全量、未选、无法编译、同义 AST 的原因。变异不代表真实 agent 提交。AST 不同也不等于数学行为错误。

**三层。** (T) 与上轮一致的全量 FAIL_TO_PASS 加至多五个预选 PASS_TO_PASS 真实节点；(M) 同样已加入上游 test_patch 的完整上下文模块，不根据 T 跳过；(I) 对所有八个金标及所有候选按独立判据运行，不根据前两层结果删选。每个模块和标签 pytest 进程上限 480 秒；每次独立判据 300 秒；最多同时两项运行。上轮 46 个完整模块最多约 15 秒，给全运行及冷启动充分裕量，多余预算不用于重复已知测试。所有 timeout/收集失败/跳过分开。金标和原基线分别跑独立判据，以区分新发现属于修复引入或旧缺陷遗留。判据先冻结、再观察候选表现；金标不通过的输入保留并单独报告，不能用作“候选相对金标退化”证据。

**预设判据。** ① 格式化带负号的取模与乘幂：给定带符号整数、非零除数，以 Python 原生 % 和幂比较执行值。② codegen.String 的 func(*args) 还原、同值/异值比较。③ Point 使用已知实数与含非零虚部的复数，包括纯虚与一般复数、正负虚部；通常模式须拒绝数值非实，evaluate(False) 下已知实坐标应可构造。④ 多参数 Min/Max 的生成代码与 Python min/max 比较。⑤ 列表、空元组、单元素及嵌套元组的调用结果与 Python 容器结构相同。⑥ 整矩阵 Hermite 标准形：二阶满秩输入用标准库 gcd、Bezout 与行列式导出列 HNF；另检验三行单列时由最后非零分量决定规范符号以及零矩阵形状。⑦ 带 cls 嵌套 symbols 指定数量、类型和名字。⑧ gamma 矩阵使用相邻哑指标收缩 γ^μγ_μ=4I，显式构造保序自由指标乘积为期望。不同输入针对同一性质，不能当作统计独立样本。

**统计。** 主要分母是 T 与 M 均通过且给定候选确实执行 I 的候选；主要终点是至少一个金标通过、候选失败的独立输入，保留具体可复验的反例。分层给出 8 个固定问题、各算子、关卡转移、候选/金标层面分母与运行成本。不把未知语义标为缺陷，不从有目的的一个开源项目推导真实生产发生率。报告跨 case 变动和相关运行时的中位数/四分位而非把相似变异当多个独立项目。在上轮 pytest 7.4.4 的新建 3.11.9 虚拟环境运行，无模型参与。
