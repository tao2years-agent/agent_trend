# 全子包对照的附加协议

写于主试验仍在运行、几何/HNF 尚未出候选结果时；仅已看见前两个其他问题原代码的性质输出。额外只选纯数学的 Point 与 HNF 两个项目版本，分别执行公开上游完整目录 sympy/geometry/tests、sympy/polys/matrices/tests。在各自 T 与 M 同时通过的候选中，优先选择 I 有金标通过/候选不通过真实反例者，按候选 ID 排序；不足两个时再从 I 没新反例者按 ID 补足。每项目最多两个入选候选，再加一份完整金标控制。若无任何幸存者，仅跑该项目金标。采用相同 3.11 独立环境、每个 pytest 进程 480 秒、至多两个并发，主试验结束后才启动。比较各测试节点与金标的成对状态、收集错误、超时和成本。在该有限扩展中未见失败不能当作语义等价。
