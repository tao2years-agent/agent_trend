# 发布版追踪

问题限定为两个已记录的数学验收反例，避免将历史提交误述为现行产品缺陷。在读取发布版行为前固定，枚举 PyPI 当前可见、现有快照研究可覆盖的 SymPy 1.9 及其后的每个 1.x 次版本，分别取最早与最后一个非预发布、非 yanked 的正式纯 Python wheel，若两者相同只取一次；截至 2026-11-20 04:50 UTC。所有输入的 SHA-256 与发布时间来自 PyPI。对每版测普通空元组、单元素、二元素、嵌套空元组的 lambdify 已知输入，以及只在一个轴放一般复数的 Point。所有组合在自己的新解释器中运行。用明确复实数输入作正反例。观察发行物的行为，不从发布时间倒推哪个合并第一次引入，也不据此评估厂商模型准确率。
