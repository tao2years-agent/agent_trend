Use CircleCI managed keys for Chunk
Jan 21, 2026
Enhancement
You can now use CircleCI managed API keys when setting up Chunk Tasks.
During setup, choose between using a CircleCI managed key or bringing your own Anthropic or OpenAI API key.
Note:
During beta, using CircleCI managed keys doesn’t incur additional costs beyond your normal compute credits. This will be a paid feature after beta.
