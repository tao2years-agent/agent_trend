Merge Queue
Queue a pull request before it's ready
November 12, 2026
The "Queue this pull request" checkbox now appears as soon as a pull request is open, not only once it's ready to be queued.
You no longer have to come back to a pull request once its reviews and CI are done just to queue it. Tick the
Queue this pull request
checkbox right after you open it, and Mergify adds it to the merge queue as soon as it meets your queue conditions, as
@mergifyio queue
does.
The checkbox shows up on every open, non-draft pull request one of your queue rules covers.
A pull request ticked early waits, then joins the queue on its own once its approvals and checks pass.
Pushing new commits after ticking it cancels the request, and the checkbox comes back so you can tick it again.
Pull requests Mergify already queues automatically don’t get one. There is nothing to turn on. To hide the checkbox, set
queue_controls_comment
to
false
, as described in
Queueing with a checkbox
.
