# 全文献目录怎样进一步减少题名偏差

前两轮对 1,738 个题名做过筛查，但用第二版词表筛掉的 64 条盲抽中仍有 23 条直接相关。为让下一次研究能从摘要和问题对象检索，尽量将八个官方研究轨的作者摘要全部归档，不把机器索引扩写成专家逐篇精读。来源仍限对应会议公共 paper detail 界面，复用既有页面、缓存和已冻结构；请求串行或低并发，记录失败及取不到摘要的目录条目。离线索引查询不再访问会议站点。

在获取剩余摘要与查看新检索结果前固定一项可复核比较：用首轮142项已有标签构建两种 TF–IDF + 逻辑回归的相关性排序器，一种只读标题，另一种同时读标题和摘要。词表只在训练集拟合、模型固定不调参。在完全互斥的二轮盲抽128条上比较排序、前20/40的直接相关数量、平均精度；注明训练只来自词命中，验证按会期与第二组词分层、不可据此推全库相关比例。可追加按届次分组误差和单侧漏检指出主题迁移。对于高分但未见且未人工判断的内容，建独立人工复核列表，逐项回到作者摘要；不得把预测标签作为已人工审核。此轮只输出自主撰写的判读、文章链接及本地数据指针，不向分享报告复制全套作者摘要。

执行记录更正术语：本预设方案中的“人工判断／人工复核”表示逐项阅读，由当前 Codex 研究代理执行。数据源的真人受访者另计。本轮没有招募人类文献审查员。
