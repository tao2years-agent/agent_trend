L975:   2. Project scope: Starting at the project root (typically the Git root), Codex walks down to your current working directory. If Codex cannot find a project root, it only checks the current directory. In each directory along the path, it checks for `AGENTS.override.md`, then `AGENTS.md`, then any fallback names in `project_doc_fallback_filenames`. Codex includes at most one file per directory.
L976:   3. Merge order: Codex concatenates files from the root down, joining them with blank lines. Files closer to your current directory override earlier guidance because they appear later in the combined prompt.
L977: Codex skips empty files and stops adding files once the combined size reaches the limit defined by `project_doc_max_bytes` (32 KiB by default). For details on these knobs, see 【572†Project instructions discovery】. Raise the limit or split instructions across nested directories when you hit the cap.

L96: # Project-Level Memory for Coder Agents in 2.39
L97: 
L98: ### What's new in 2.39
L99: 
L100: Give Coder Agents your conventions, context, and skills once, at the project or organization level, and every chat builds on them. Platform teams can also trace any workspace connection end to end and see every editor their developers use.
L101: ### Coder Agents: Shared context and admin controls
L102: 
L103: Set conventions, skills, and model access once instead of repeating them in every chat or organization.
L104:   * Organization skills and instructions: Admins publish 【38†skills】 and 【39†instructions】 once per organization, can limit them to specific groups, and every change is recorded in the 【40†audit log】.
L105:   * Manage model access in Terraform: The coderd Terraform provider can now set which users and groups can use each Coder Agents model, and configure Claude Platform for AWS. 【41†View the provider release†github.com】.
L106:   * Projects: Group related chats in 【42†projects】 with shared memory, instructions, and 【43†skills】, so each new chat builds on the last one.
L107: 【44†Image†www.datocms-assets.com】
L108: ### Script ordering for templates
L109: 
L110: Template authors can set the order `coder_script` resources run with the new 【45†`coder_script_order`】 data source, so dependencies install before an IDE or AI coding agent starts. It's in beta, opt-in, and requires Coder Terraform provider v2.20.0 or later. 【46†Learn more in our documentation】.
L111: ### More improvements
L112:   * Trace any workspace connection end to end: VS Code, JetBrains Toolbox, `coder ssh` and the web terminal tag each session with one ID across client, server and agent logs, so platform teams can find why a connection dropped in a single SIEM search, without debug flags. 【47†Learn how to trace workspace connections】.
L113:   * See every editor your developers use: Template Insights, connection logs, and Prometheus now track each editor by name, including VS Code forks such as Cursor. See the 【48†connection logs】 and 【49†Prometheus】 docs.
L114:   * VS Code extension 1.17: Developers now see a warning when a startup script fails or times out. Version 1.17.0 also includes a 【50†security fix†github.com】, so we recommend updating. Learn more in our 【51†documentation】.
L115: ### Security updates
L116: 
L117: We've recently patched several disclosed vulnerabilities. Check our 【52†security advisories†github.com】, and 【53†watch for new releases†github.com】 on GitHub to hear about patches first. For updates on vulnerabilities we have patched, visit the 【54†Coder Trust Center†trust.coder.com】.
L118: ### Breaking Changes
L119:   * 【55†#30466†github.com】: A migration rewrites the `connection_logs` table under a lock that blocks reads and writes, about 50 seconds per 10 million rows. Plan a maintenance window for large deployments.
L120:   * 【56†#29796†github.com】, 【57†#29906†github.com】: Template insights and the `coderd_insights_applications_usage_seconds` metric now report per app. In the API, `type` is replaced by `method`. In the metric, `application_name` is now `display_name`. Update dashboards, alerts and scripts.
L121:   * 【58†#30150†github.com】, 【59†#30140†github.com】, 【60†#30199†github.com】: `coder update` and `coder users edit-roles --roles` now ask for confirmation, so scripts need `-y`. `coder update` also returns an error if the restart fails.
L122:   * 【61†#31262†github.com】: Template builds fail if a `coder_app` URL uses an unsafe scheme such as `javascript:`. Check templates before upgrading.
L123:   * 【62†#30256†github.com】: API keys created from a scoped token can't go beyond that token's scopes.
