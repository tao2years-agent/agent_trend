# Manage your Teamwork Graph connectors

Teamwork Graph connectors enable you to connect third-party app s outside Atlassian to enhance Rovo Agents, Search, and Chat. Before connecting to a third-party app, we recommend reviewing the types of data stored in that app, and confirming that connecting the data aligns with your internal data use policies and practices.

## Types of connectors

There are three types of connectors:

  1. Synced connectors: Providing the highest quality for your search and chat, these connectors are setup by an Admin to sync all your workspace content.

  2. Direct connectors: Direct connector content is retrieved live through the provider's search APIs. Content is not stored or indexed by Atlassian.

  3. Smart Link connectors: Don’t need to be setup by an admin, and instead use Smart Link data to show results based on an individual user’s permissions and history.

For more details on the differences between these connectors, see Teamwork Graph connector types.

## Permissions

The Teamwork Graph relies on and respects the permissions that are set in your third-party apps. Content that isn’t restricted may appear for all users in search results, or can be used by Agents or Chat. More on how permissions are kept in sync

## Connectors that require an admin to setup

To set up connectors, you need to have organization admin permissions in admin.atlassian.com. Learn about permissions

### Connectors per site

On each site, most connectors can only be used to connect to a single workspace. This means that:

  * On a single site with Rovo (for example, yoursite.atlassian.net), you can only connect each app once (Google Drive)

  * Each different site with Rovo can connect to a different app workspace (your company's Google Drive) using its own connector.

The only connectors that can be set up multiple times on a single site with Rovo are the Custom website connector and the Jira Data Center Connector.

### After admin setup

Users may need to connect to the external apps to ensure they see only the data they have permission to access. They might not have to perform this step if they have previously connected their Atlassian account to the app.

Once the connector is set up and the user has connected it with the app, that data can be used and shown in Search, Chat, and Agents.

### Monitor connector health

You can easily see if your connectors are syncing, disconnecting or require attention. Just select the status icon for more info and steps to fix any issues, like re-authenticating or updating permissions. We suggest checking your connectors page often to keep everything running smoothly.

## Permissions

Rovo synchronises with access controls and permission settings from connected third-party app s and your Atlassian app s. This helps ensure that users only see content they have access to.

Because Rovo relies on these permissions you have set, before connecting a third-party app you should check and remind users to check the permissions set up for that app.

For example, if you connect Google Drive to Rovo, users need to log in and connect their Atlassian account to Google Drive to see any Google Drive results in Rovo. Once authorized, users will be able to see public documents and private documents that they already had access to.

For supported synced connectors, an admin can also turn on Allow users to see results without connecting their account.

When this setting is on, users may see that connector's results in Rovo Search, Chat, and Agents without connecting their account. Access permissions are still respected, using permissions synced from the connected app.

We ‘listen’ for permission changes, and update the Rovo index with changes. More about permissions

## Deleted data

For admin managed connectors, we ‘listen’ for content deletion, and update the Rovo index with changes. For example, once the Rovo index is updated, content that’s deleted from a connected third-party app will not appear in Rovo results. For more information on permissions and connectors, see Manage Rovo connectors.

For Smart Link connectors, deleted Smart Links may still show up in Search Results. However, if a user clicks on a link to deleted content or clicks on a link they no longer have access to, the link will appear broken. See Search with Smart Links for more information.

If an organization admin disconnects a third-party app from Rovo, we will delete the content we've indexed from the third-party app within 30 days. --------------------------------------------------------------------------------

# How Teamwork Graph connector permissions are kept in sync

Once you’ve set up an admin-managed connector, Rovo sets up a secure sync with the third-party app. When new content is created or removed in that app, the relevant information is synced with Rovo.

This means restricted data in your connected third-party app s (for example, a private file or folder in Google Drive) can only be seen and used in Rovo by those users who already have access to that content in such third-party app s.

# Admin Enabled Authentication for synced Teamwork Graph connectors

Admin Enabled Authentication lets organization admins allow users to see results from supported synced Teamwork Graph connectors without connecting their own account to the third-party app first.

Rovo still respects each user's existing permissions. Users only see content they are allowed to access in the connected app.

The connector setting is called Allow users to see results without connecting their account.

## Where Admin Enabled Authentication applies

Admin Enabled Authentication applies when Rovo reads content from the Teamwork Graph, including Rovo Search, Chat, and Agents.

It does not apply to tools and actions that act in a third-party app. Tools and actions still require each user to connect and authenticate with their own account, because they act on that user's behalf.

Smart Link connectors and other non-synced connectors are not covered by this setting. Users still need to connect their own account for those connectors.


## What happens if permissions are not current

For connectors with a permission freshness window, Rovo checks that permission updates from the connected app are received and applied within that window.

If Rovo cannot confirm that a connector's permissions are complete and current, results from that connector stop appearing in Rovo Search, Chat, and Agents until permissions can be confirmed again.

Results return automatically when syncing recovers. No admin or user action is needed.

Salesforce works differently. Salesforce permissions are validated for each query, so a permission freshness window does not apply.

## What users see

When the setting is on, matched users can see results from the connector without a separate connection step. Results are limited to content they are permitted to see.

Users may still be prompted to connect their own account when:

  * the connector does not support Admin Enabled Authentication

  * the setting is off for that connector

  * Rovo cannot match the user's Atlassian account to their third-party account

# Check status of indexed content

When you connect a third-party app to Teamwork Graph using a synced connector, Teamwork Graph indexes content from that app. This makes the content available in Rovo Search, Chat, and Agents for people who have permission to see it in the third-party app.

Use Check index status to confirm whether a specific file, document, or record is in the Teamwork Graph index. Paste a link to the item to see whether it's indexed and, when available, the date the indexed version was last modified.

This helps you investigate content someone expects to find but can't, validate a newly connected app, or check whether a recent change to your content has taken effect.

## Before you begin

  * You need to have organization admin permissions in admin.atlassian.com. Learn about permissions

  * The connector needs to be set up already. See Manage your Teamwork Graph connectors

  * The index check is available for synced connectors. Direct connectors retrieve results live and don't store or index content with Atlassian, so there's nothing to check. See Teamwork Graph connector types

## Check index status

  1. Go to admin.atlassian.com. If you have more than one organization, select the one you want.

  2. Select Connectors, then open the connector that holds the content.

  3. Go to the Check index status section.

  4. Paste the link to the content you want to check. Use the link you'd normally copy from the third-party app — for example, the Copy link or Share link for a Google Drive file, or the address bar URL for a ServiceNow incident.

  5. Select Check status.

The check is read-only. It doesn't start a sync, change any content, or change anyone's permissions.

## Solution

Administrators have full oversight and control over these connections through Atlassian Administration.

### 1. Monitor Activity

To see when and which users authorized these connections:

  1. Go to Atlassian Administration > Insights > Audit log.

  2. Filter the log for "Rovo MCP" to view user authorization events.

### 2. Manage Permissions

You can restrict or disable access to these MCP servers:

  1. Navigate to Atlassian Administration > Rovo > Rovo MCP server > Permissions.

  2. Adjust access by permission type (Read, Write, Search) or by specific product.

  3. You can also disable the MCP server entirely for your organization if required.

Note: The permissions set in the Rovo MCP server tab take precedence over any settings found directly within the Connected Apps page.

# Connect Salesforce to Teamwork Graph

You can use Teamwork Graph Connectors to search or chat across Salesforce data alongside your company knowledge.

Salesforce offers two connector options:

  * Synced connector indexes your Salesforce data into Teamwork Graph and supports Salesforce across search, chat, and agents.

  * Direct connector does not index any data into Teamwork Graph; instead it relies on real-time calls to Salesforce's MCP, and it works only in Rovo Chat and agents (it does not support search). Choose the option that best fits your needs.

### Compare connector options

   | Synced connector  | Direct connector
--- | --- | ---
Data handling  | Indexes Salesforce data into Teamwork Graph  | Does not index any data; makes real-time calls to Salesforce's MCP
Where it works  | Search, Chat, and Agents  | Rovo Chat and Agents only (no Search)
Permissions  | Salesforce permissions respected; integration account used for indexing  | Salesforce permissions respected; uses each user's own Salesforce access at runtime
